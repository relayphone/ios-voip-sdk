GUI proof uses identical inspector Swift source on an earlier runtime base,
Xcode 26.6/iOS 26.2. Current native CI uses iOS 26.5; both use the measured
`ios-27.0` profile. Latency is a simulator handler measurement. GUI acceptance
runs only on explicit workflow dispatch because hosted XCTest repeatedly failed
before starting a case; those failures remain visible. PR/main builds, bridge
and native channel checks remain automatic, alongside required SDK acceptance.
The first main native attempt missed the initial fixture call; its unchanged
retry passed. No failure journal was retained, so the cause remains unresolved.

Build with `bash scripts/build-inspector.sh discovery/out/inspector`, then:

```sh
Tools/cksim --simulator <target-UUID> --bundle <app.bundle.id> \
  --runtime-dir <package> inspect --app discovery/out/inspector/CKSimInspector.app
```

Use the same target arguments with `watch` or `watch --json` for the full journal.
The iPhone MVP uses a separate disposable display simulator to keep the target
app foregrounded, retaining 300 timeline events and five ended conversations.
See the [runtime guide](../simulator-runtime.md#swiftui-call-inspector-m4-mvp).
No receipts or screenshots are committed; no physical device was used.
