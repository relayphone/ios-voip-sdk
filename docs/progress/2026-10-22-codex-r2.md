# R2: concrete ABI guards

**Measured by final native acceptance:** install verifies all 22 CallKit hooks on the resolved concrete provider, controller, observer and supported action classes. Provider and controller initialization uses separate public and concrete original implementations, correct retained/consumed ARC conventions and outermost-only registration. The action hierarchy captures original implementations before mutation and hooks every covered superclass so original-to-super forwarding runs once.

The snapshot preflight toggles and reads back all four KVC keys and catches Objective-C exceptions. Unsupported selectors and snapshot failures retain inactive report/request guards: a diagnostic `CKSimRuntimeErrorDomain` error, empty snapshots and inert mutators. They never restore genuine report/request methods after refusal. Shadow mode refuses differing concrete incoming/delegate originals before binding. PushKit's three hooks also preflight and verify their concrete implementations.

**Measured:** [R2 evidence](../verification/2026-10-22-runtime-r2/README.md) includes the v0.1 concrete incoming-report failure and eight passing primary scenarios with 13 checks each. That passing capture predates the final action-superclass forwarding fix and does not qualify it. The final candidate compiles for arm64 and x86_64; both fault controls are absent from shipping builds. Standards and Spec reviews are clean after addressing their forwarding and missing-selector-test findings.

**Measured:** the frozen final candidate passes all eight cases and 18 checks per case (144 total). The [final receipts](../verification/2026-10-22-runtime-r2/green-final-8x18/summary.json) bind the native traces, binary identities, app PIDs and run identity. The extended probe compares untracked fulfillment, failure, deadline and dated fulfillment with genuine preload references, and checks original dispatch through leaf/intermediate/inheriting-sibling action classes. The owned simulator was shut down and deleted.

**Pending CI:** the full discovery suite, including its existing normal shadow push lane, must pass before merge. That lane establishes compatibility without the ABI probe's concrete-method sentinels.

No RFC 0001 API deviation, upstream action, license addition or R3 teardown change is included. Device and LCK measurements remain separate acceptance targets.
