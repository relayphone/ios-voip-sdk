# R9: CI runtime releases

**Proposed acceptance:** the next standalone runtime prerelease is v0.1.1. A successful `runtime-release.yml` annotated-tag run must build, fully qualify, package, attest, verify and publish its own distribution. No tag, push or release was created while preparing this change. The historical v0.1 release stays unchanged.

The change adds a single `VERSION` source; embeds it in the runtime and build information; binds loaded/package/manifest versions in discovery; records Xcode, Swift, Clang, SDK version/build, architectures and source identity; and normalizes tar ownership, order, modes and timestamps. The workflow refuses lightweight tags and tags on commits not merged into main. It packages `out/runtime-dist` only after `discovery/run.sh` succeeds, attests the archive/checksums/qualification, verifies the expected source/workflow, then publishes a prerelease. [Release instructions and verified primary sources](../runtime-releases.md) describe the contract.
