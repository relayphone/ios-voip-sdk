**Implemented; local and earlier hosted native acceptance measured, current integrated hosted acceptance pending.** The Swift package keeps a dependency-free media protocol and default no-op adapter. The iOS Expo product selects one native binding at prebuild time: standard WebRTC's public manual-audio contract, the React Native LiveKit module's existing audio device module, or `none`. Native worker queues keep backend operations off MainActor. A current authorization value prevents queued stale activation after a genuine deactivation/reset; no recovery path fabricates system activation.

The core uses a 10-second activation deadline and 5-second recovery grace by default, emits missing/failed signals, attempts one finite category/mode recovery and cleanly ends affected conversations. Actual LCK joined/unheld state drives demand. Routes project AVAudioSession inputs/current outputs and the speaker override; the public hook uses revisioned immutable snapshots and preserves explicit route loss. The plugin adds background audio for media bindings, preserves existing modes and keeps `none` free of media dependencies.
